# Следующие пять задач: независимый поиск на Rust

Дата: 09.10.2026. Основная документация репозитория — на английском.

Завершены пять задач:

1. Описан отдельный ограниченный протокол обмена SCP1/SCR1.
2. Написан независимый Rust-поиск: до трёх ненулевых координат, коэффициенты ±1/±2.
3. Добавлен Python-клиент: ограничения входа/выхода, тайм-аут, проверка каждого
   ответа и запрет использования частичного результата при ошибке.
4. Добавлены сверки порядка, счётчиков, предельных параметров и позднего решения.
5. Проведены локальные замеры и новые серии переноса решений между матрицами.

Прошли309 тестов Python,23 Rust, форматирование, clippy и прежние наборы сверок.
Новый набор:768 сравнений Rust/Python без расхождений,7352 проверки полученных
векторов,48 случаев с независимым полным перебором маленького пространства,
16 отклонённых ошибочных входов. На предельной матрице64×16 Rust проверил все
18912 кандидатов и вернул все шесть ожидаемых решений, включая позднее
`(0,...,0,2,2,2)`. Копии одного направления остаются допустимыми, но зависимыми.

Локальная серия содержит312 сравнений времени и192 оплаченных поиска для новых
матриц и контрольных повторов. Независимый Rust-проверяющий подтвердил3054
положительных/отрицательных результата. Перенос на новую матрицу сработал54 раза
из515 проверок; на повторяющейся контрольной —486 из486. Это наблюдения
зависимых пулов, а не независимая статистика или доказательство экономии работы.

Замер внутренней работы Rust существенно ниже замера Python в выбранных
случаях. В отчёте отдельно показаны работа Rust, вызов Python и обмен с новым
процессом. Границы этих замеров различаются, поэтому коэффициент общего
ускорения не заявлен. Клиент дополнительно повторяет поиск на Python, чтобы
полностью проверить ответ; это время находится за пределами замера обмена.

Решения и счётчики совпадают. Правила консенсуса и допустимости SIS1 не менялись.
Это пока небольшой исследовательский поиск, не готовый майнер и не доказанная
экономическая модель PoW. GPU, серверный майнер и GitHub Actions не использовались.
