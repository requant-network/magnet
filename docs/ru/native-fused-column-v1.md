# Нативный CPU и единое CUDA-ядро поиска

Вторичный перевод. Актуальный основной документ:
[Native CPU and fused CUDA column search](../research/native-fused-column-v1.md).
Дата: 2026-10-09.

Завершены три задачи: независимый оптимизированный поиск на Rust, единое
CUDA-ядро и сравнение четырёх реализаций на локальной CMP 50HX. Все 600 запусков
совпали; 4416 возвращённых результатов проверены отдельным Rust-верификатором.

Ищем тот же ограниченный набор векторов: сначала единичные координаты, затем
пары с коэффициентами +1/+1 и +1/−1. При B2=1 остаются только одиночные
координаты. Это исследовательский поиск, без изменения правил блокчейна.

Rust один раз подготавливает столбцы и быстро отбрасывает неверные кандидаты.
CUDA вычисляет координаты кандидата прямо в ядре, проверяет остатки и возвращает
по одному байту результата. Полные векторы создаются только для выдачи.
Весь проверенный пакет учитывается даже при достижении лимита результатов.

Суммарное время за три повторения, миллисекунды:

| Вариант | 126 обычных запусков | 24 запуска с большими пакетами |
|---|---:|---:|
| Python, столбцы | 112,793 | 144,746 |
| Rust, только внутренняя работа | 2,048 | 1,478 |
| PyTorch CUDA | 629,621 | 47,608 |
| Единое CUDA-ядро | 105,889 | 22,671 |

CUDA-ядро уменьшило время относительно PyTorch примерно в 5,95 и 2,10 раза
на данном наборе. При этом область измерения Rust отличается: полный обмен
с процессом и проверка результатов заняли ещё отдельно учтённые 604,157 мс,
включая внутренние 3,526 мс вычислений. Полный адаптер делает дополнительные
проверки, которых нет внутри GPU-таймера. Эти числа нельзя объявлять честным
сравнением скорости готовых CPU/GPU-майнеров.

Каждый GPU-запуск заново выделяет память и передаёт матрицу. Видеокарта хранит
только матрицу и маску результатов; максимальный размер этих буферов в опыте —
65600 байт. Это не общее потребление GPU и не доказательство memory hardness.
Дополнительно проверены 88076 позиций полного порядка кандидатов, маски для
16804 кандидатов и отказ на 14 некорректных запросах непосредственно в C ABI.

Локальные проверки: 244 Python-теста и 21 Rust-тест, форматирование, clippy и
дифференциальные корпуса. Новый корпус Rust/Python: 373 задачи без расхождений.
Зафиксированы 174 хеша исходников, бинарные файлы и параметры компилятора.
Использованы существующие nvcc 13.3.73 и PyTorch; облако и GitHub Actions не
потребовались. Майнер на GPU не работал при проверках до и после опыта;
ComfyUI оставался запущенным. Полной изоляции нагрузки не было.

Далее полезно сравнить одинаковые способы интеграции CPU/GPU без затрат на
отдельный процесс и расширить семейства кандидатов. Выводы о безопасности PoW,
сложности, экономике или параметрах основной сети пока делать рано.
