# Первая проверка SIS на видеокарте

Вторичное русское описание этапа от 2026-10-09.
[Основной отчёт](../research/gpu-verification-v1.md).

На локальной CMP 50HX выполнена точная пакетная проверка решений SIS через CUDA.
Из 731 случая 470 действительно вычислялись на видеокарте: 228 приняты,
242 отклонены по модульным уравнениям. Остальные 261 отклонены проверками формата,
знака или нормы на CPU. Итоговые ответы совпали с Python и независимым Rust:
расхождений нет. Один слишком большой транспортный пакет проверен в Rust
отдельно, поскольку он должен завершать обработчик с ошибкой.

GPU считает целочисленные произведения и суммы в int64. Сырые координаты сначала
проходят точные проверки на CPU, чтобы переполнение не превратилось в допустимый
результат. Размеры пакетов и партий ограничены. Пиковые выделения PyTorch —
около 4 MiB, резервирование — 22 MiB; это не полная память CUDA и не гарантия
memory-hardness. При отсутствии CUDA скрытого перехода на CPU нет.

Майнер остановлен с разрешения владельца для GPU-работы; контейнер сохранён.
После перерыва обнаружено, что он снова работает. Причина повторного запуска
не установлена. Скорость в изолированных условиях не измерялась. Доступы и ключи
не попадали в репозиторий, пакеты не устанавливали, GitHub Actions не использовали.

Прошли 214 тестов Python, 19 Rust и прежние межъязыковые проверки. Результаты,
seed и хеши сохранены. Это готовый компонент проверки на GPU; полноценный
GPU-майнер ещё не написан. Следующий этап — генерация и проверка собственных
кандидатов с учётом всех затрат, затем честное сравнение CPU/GPU. Параметры
производственного консенсуса пока не выбраны.
