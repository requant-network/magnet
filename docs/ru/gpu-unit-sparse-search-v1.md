# GPU теперь сам ищет кандидатов SIS

Вторичное описание этапа от 2026-10-09.
[Основной отчёт](../research/gpu-unit-sparse-search-v1.md).

Добавлен ограниченный поиск: CUDA сама генерирует векторы с одной или двумя
ненулевыми координатами ±1, проверяет их и возвращает подходящие решения.
Готовые решения с CPU ей не передаются. Это ещё не полноценный майнер блоков.

На CMP 50HX выполнены 42 пары CPU/GPU — всего 84 запуска. Результаты,
остановки и общие счётчики совпали. Каждый вариант проверил 71424 кандидата,
увидел 391 подходящий и вернул 368 результатов с учётом повторов; разница
связана с лимитом выдачи внутри уже обработанного пакета. Все 736 возвращённых
результатов обоих вариантов приняты независимым Rust. Отдельно проверены
порядок и генерация 53260 кандидатов GPU.

Из 42 пар 30 относятся к десяти новым матрицам с повтором настроек, ещё 12 —
к специальным нулевым/единичным матрицам и граничным случаям. В GPU-результатах
79 выдач на обычных тестовых матрицах и 289 на специальных. Эти числа нельзя
считать количеством новых блоков или независимых решённых задач SIS.

Ускорение пока не показано: суммарное время поиска GPU — около 7,30 секунды,
Python — 3,22 секунды в этом запуске. Это первый плотный прототип с малыми
пакетами, а не сравнение с оптимизированным CPU-майнером. Майнер выключен для
исследования и при первой проверке после запуска был остановлен. При более
поздней проверке он снова работал; также присутствовал процесс ComfyUI.
Причина повторного запуска не исследовалась, условия не считаются изолированными.

Прошли 223 теста Python, 19 Rust и прежние межъязыковые проверки. Затраты
генерации, проверок и явной передачи данных сохранены отдельно; лимиты не
превращают неудачные попытки в бесплатные. Исследование не использовало
GitHub Actions или платные вычисления.

Следующий шаг — заменить плотные операции сложением/вычитанием нужных столбцов
матрицы, создавать полный вектор только для выдачи и сократить синхронизации.
Потом расширять поиск и сравнивать с сильными CPU-алгоритмами. Сложность,
вес цепи и денежные правила по-прежнему не выбраны.
