# CPU/GPU в одинаковых условиях и поиск троек

Дата: 9 октября 2026 года. Это исследовательский этап, а не готовый майнер.
Основной [английский отчёт](../research/matched-sparse-v1.md) содержит контракт,
методику, ссылки на исходники и машиночитаемые результаты.

## Что сделали

1. Добавили поиск на CPU и GPU через один интерфейс с одинаковыми правилами
   проверки входа, остановки, выдачи результатов и учёта работы. Каждый запуск
   оплачивает подготовку, копирование, поиск и освобождение своих ресурсов.
2. Расширили семейство кандидатов: теперь проверяем векторы с тремя ненулевыми
   координатами ±1, а не только с одной или двумя.
3. Провели локальное сравнение на CMP 50HX, независимые проверки и сохранили
   результаты вместе с хешами исходников и собранных программ.

Все **504 запуска** совпали с независимой Python-проверкой. Rust-верификатор
принял **7584 возвращённых результата**; повторные появления одного решения
считаются отдельными проверками, а не новыми независимыми открытиями.
Локальные проверки: **266 Python-тестов и 21 Rust-тест**, форматирование,
линтер и прежние межъязыковые проверки.

## Что узнали

Тройки действительно находят дополнительные решения. Например, для строки
[1,2,3] по модулю 17 подходит (1,1,-1), хотя одиночные координаты и пары решения
не дают. Значит, изучать только пары недостаточно для оценки стоимости PoW.

В измеренных группах суммарное время CPU оказалось меньше времени GPU.
Большие порции уменьшают расходы GPU; для троек при больших порциях результаты
близки. Это относится к текущему скалярному CPU, ядру, параметрам и расписанию,
а не доказывает преимущество CPU для любого будущего алгоритма.

| Группа, сумма трёх повторений | CPU, мс | GPU, мс |
| --- | ---: | ---: |
| Небольшие порции, пары | 32,314 | 87,505 |
| Небольшие порции, тройки | 140,513 | 494,690 |
| Большие порции, пары | 23,415 | 50,825 |
| Большие порции, тройки | 76,942 | 83,189 |
| Короткий префикс, пары | 15,471 | 25,109 |
| Короткий префикс, тройки | 15,221 | 23,567 |
| Специальные примеры, пары | 18,203 | 200,067 |
| Специальные примеры, тройки | 18,211 | 24,157 |

В GPU-измерениях сохранён отдельный скачок до 171,379 мс. Причину не установили;
не удаляем его ради красивого результата. Загрузка библиотеки, первый запуск
GPU, компиляция и независимые проверки измерены отдельно.

## Ограничения результата

При 128 координатах полное семейство содержит 1381888 кандидатов, но обычный
поиск ограничен 65536. Он проверяет все одиночные координаты и пары, затем
только 3,60% троек, преимущественно с ранними координатами. По этой выборке
нельзя оценивать долю решений среди всех троек. Повторы и разные размеры порций
используют общие матрицы и не являются независимыми испытаниями.

Полный порядок кандидатов проверен отдельно: 1423296 позиций для каждого
backend, включая всё максимальное семейство. Проверены границы C-интерфейса,
остатки по модулю, переходы между весами и остановки. Успешные порции считаются
целиком, даже если часть найденного уже не помещается в выдачу. Ошибки сохраняют
известную работу, неизвестные счётчики и не дают успешных сравнений времени.

Мы не меняли консенсус, параметры безопасности или формулу сложности. Следующий
шаг — другие семейства решений с коэффициентами шире ±1 и стоимость получения
и повторного использования решений на свежих задачах. Облачные GPU и GitHub
Actions не использовались; майнер на локальной карте был выключен.
