# Оптимизация GPU-поиска через столбцы матрицы

Вторичное описание этапа от 2026-10-09.
[Основной отчёт](../research/gpu-column-search-v1.md).

Новый поиск проверяет только два нужных столбца матрицы. CUDA сама создаёт
индексы и знаки кандидатов, возвращает одну маску подходящих решений на пакет,
а полный вектор создаётся на CPU только для выдачи результата. Готовые решения
с CPU в GPU-поиск не передаются. Прежний плотный вариант сохранён для сравнения.

Выполнено 184 запуска: 42 прежних случая с четырьмя алгоритмами и ещё восемь
случаев с крупными пакетами для двух вариантов работы со столбцами. Решения,
остановки и общие счётчики совпали. Все 1472 выданных результата с учётом
повторов приняты независимым Rust. Отдельно проверен порядок 88076 кандидатов.

На прежнем наборе текущий GPU-вариант через столбцы затратил около 0,216 секунды,
плотный GPU — 0,536 секунды: примерно в 2,48 раза меньше времени в этом запуске.
CPU с такой же оптимизацией затратил только 0,037 секунды, поэтому общего
превосходства GPU над CPU пока нет. На наборе с крупными пакетами GPU показал
15,86 мс против 32,57 мс у Python через столбцы, но все эти случаи были без
решений. Это не сравнение с оптимизированным нативным майнером.

На прежнем наборе число логических элементов полных векторов снизилось
с 8577100 до 33510, явная передача GPU→CPU — с 279792 до 71424 байт.
Лимит внутри пакета не скрывает затраты: все уже обработанные кандидаты,
включая подходящий хвост сверх лимита выдачи, оплачены в счётчиках.
Алгоритм по-прежнему ищет только векторы с одной/двумя координатами ±1.

Прошли 231 тест Python, 19 Rust и межъязыковые проверки. Майнер на CMP
остановлен для запусков и после серии был выключен; ComfyUI остался загружен.
Условия не полностью изолированы, поэтому цифры времени описывают этот запуск,
а не гарантированный хешрейт. GitHub Actions и платные вычисления не использовали.

Следующий этап — сильный нативный CPU-вариант на Rust для честного сравнения,
затем объединённые CUDA-ядра и расширение поиска. Правила сложности, веса цепи
и денежного протокола пока не выбирались.
