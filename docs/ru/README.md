## Результат следующего эксперимента

Исследованы 320 маленьких матриц. Из одного известного решения в некоторых
случаях удалось получить до пяти допустимых векторов, включая исходный, через
простые преобразования. Из двух решений можно получать новые линейными
комбинациями. Требование общего делителя координат, равного единице, само по
себе этого не устраняет.

Поэтому нельзя считать каждое новое доказательство или хеш-попытку отдельным
полным SIS-вычислением. Это ограничение рассматриваемой модели учёта работы,
а не доказательство невозможности любого SIS-PoW.

Актуальные подробности: [отчёт об эксперименте](../research/solution-reuse-v1.md),
[решение ADR 0002](../decisions/0002-solution-reuse.md),
[состояние проекта](../STATUS.md). Исходные векторы для эксперимента получены
полным перебором; ускорение настоящего майнинга здесь не измерялось.

## Стратегии поиска с учётом первоначального решения

Следующий эксперимент сравнил четыре стратегии на 448 маленьких матрицах.
Стратегии сами находят первое решение, а общие счётчики учитывают и неудачные
поиски. Повторное использование решения даёт дополнительные хеш-попытки с
небольшими дополнительными вычислениями. Разреженный поиск иногда уменьшает
перебор, но увеличивает матричные операции: одного счётчика для сравнения мало.

Это учёт отдельных операций, а не измерение скорости майнинга или готовая
формула сложности. Подробности и результаты: [английский отчёт](../research/search-strategies-v1.md).
Следующий этап — ограниченный поиск методом «встреча посередине» и сравнение
затрат памяти и вычислений. Консенсус и учёт накопленной работы пока не выбраны.
