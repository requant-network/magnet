# Repository language policy

English is primary for code comments, identifiers, specifications, ADRs, README
files, research reports, issues and commit messages.

Russian is secondary under docs/ru/. Translations and snapshots must link to the
authoritative English document and state their scope or revision. Technical
decisions are recorded in English. Existing Russian documents were preserved as
initial-phase snapshots on 2026-10-08; their test counts are historical unless
explicitly updated.
